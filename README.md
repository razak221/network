# Pristine Decore (pristinedecore.com)
### Turnkey Civil Construction & Luxury Interior Architecture Studio

Pristine Decore is a premier architectural and civil engineering studio delivering turnkey residential villas, bespoke luxury interiors, Italian modular kitchens, and premium commercial fitouts backed by transparent fixed-price BOQs and a 10-year structural warranty.

---

## 🚀 Key Disciplines & Capabilities

1. **Turnkey Civil Construction & Structural Engineering:**
   - Certified foundation piling, geotechnical soil bearing analysis, and deep substructure tanking.
   - Seismic-compliant RCC framing (IS 456 & IS 1893) using primary-grade Fe-550D TMT steel and 53-grade concrete.
   - 10-Year Comprehensive Structural Warranty backed by lab-tested cube compression reports.

2. **Luxury Interior Architecture & Bespoke Millwork:**
   - Precision modular European kitchens with Blum/Hettich soft-close hardware and quartz/granite surfaces.
   - Bookmatched Italian marble flooring (Statuario, Bottochino, Travertine) with diamond polish.
   - Custom fluted veneer wall panelling, walk-in wardrobes, and acoustic false ceilings.
   - Zero-VOC Italian polyurethane (PU) finishes.

3. **Commercial Fitouts & Statutory Governance:**
   - High-end corporate headquarters, retail flagship boutiques, and commercial complexes.
   - Acoustic drywall partitioning, centralized VRV/HVAC ducting, and NBC 2016 fire compliance.
   - Dedicated senior site engineer stationed full-time on-site with daily digital logs.

4. **Real-Time Cost Estimator & Interactive 3D BOQ Studio:**
   - Interactive square-footage calculator by typology and finish tier (Premium, Luxury, Royal).
   - Interactive 3D perspective architectural visualizer with CAD markings, camera presets, marble/oak finish swatches, and day/night lighting.
   - Instant printable B2B proposal and itemized Bill of Quantities (BOQ) with WhatsApp dispatch.

5. **Bespoke Materials & Rare Fixtures Concierge:**
   - On-demand procurement for rare quarried marble slabs, solid Burma teak doors, smart switchable glass, and custom brass hardware.

## 🛠️ Local Development

```bash
# 1. Install frontend dependencies
npm install

# 2. Start local Vite frontend server (runs on http://localhost:5173)
npm run dev

# 3. Start local backend API server (optional, port 5001)
node server/index.js

# 4. Run automated QA test suite (100 tests)
npm test

# 5. Build for production
npm run build
```
